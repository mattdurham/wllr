📦 INSTALLATION
  go install golang.org/x/tools/gopls@latest        # Go
  pip install python-lsp-server                     # Python
  npm i -g typescript-language-server typescript    # JS/TS
  rustup component add rust-analyzer                # Rust

🔍 DETECT INSTALLED SERVERS
  {"action": "detect"}

🚀 START SERVER (AUTO)
  {"file": "main.go"}                               # Auto-detects Go
  {"file": "script.py"}                             # Auto-detects Python

🚀 START SERVER (MANUAL)
  {"action": "start", "name": "go", "cmd": "gopls"}

📞 CALL LSP METHODS
  Completion:
    {"action": "call", "server": "go", 
     "method": "textDocument/completion",
     "params": {"textDocument": {"uri": "file:///.../main.go"},
                "position": {"line": 10, "character": 5}}}

  Hover (docs):
    {"action": "call", "server": "go",

🗂️  SUPPORTED LANGUAGES
  .go       → gopls
  .py       → pylsp
  .js/.jsx  → typescript-language-server
  .ts/.tsx  → typescript-language-server
  .rs       → rust-analyzer
  .c/.h     → clangd
  .cpp/.hpp → clangd
  .java     → jdtls
  .rb       → solargraph
  .php      → intelephense
  .cs       → omnisharp
  .lua      → lua-language-server
  .sh       → bash-language-server
  .json     → vscode-json-languageserver
  .yaml     → yaml-language-server

📚 COMMON LSP METHODS
  textDocument/completion       # Code completion
  textDocument/hover            # Documentation
  textDocument/definition       # Go to definition
  textDocument/references       # Find all references
  textDocument/documentSymbol   # Outline/symbols
  textDocument/formatting       # Format code
  textDocument/codeAction       # Quick fixes
  textDocument/rename           # Rename symbol
  textDocument/signatureHelp    # Function signatures
  textDocument/diagnostic       # Errors/warnings
